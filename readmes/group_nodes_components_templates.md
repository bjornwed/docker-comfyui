- Template: A feature that allows you to save and load parts of a workflow.
(https://www.youtube.com/watch?v=ELDJxPTz3kw)
Note: does not support group nodes!


- Group Node: A feature that allows you to convert parts of a workflow into a group for reuse within the same workflow.
(Due to its nature, it is belongs to the workflow. It cannot be used in other workflows.)

- Component: This is not an official feature of ComfyUI. If referring to a component provided by ComfyUI-Manager, it is an application of the group node feature that allows group nodes to be saved to disk and reused across multiple workflows.
Component package files can be located in custom_nodes/ComfyUI-Manager/components. Currently components cannot be deleted through UI, but files needs to be manually altered/removed from disk.
